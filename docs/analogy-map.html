🗺️ उपमांचा नकाशा — तीच शाळा, चार कोर्स

मालिका मुद्दाम एकच उपमांचे विश्व पुन्हा वापरते: Docker शाळेत CI म्हणून भेटलेला कुरिअर रोबोट इथे push pipeline आहे, आणि केअरटेकर रोबोट म्हणजे ArgoCD. हा तक्ता चारही कोर्समधल्या उपमा एका रांगेत लावतो म्हणजे ज्ञान सहज पुढे जाते — प्रत्येक cell तो शिकवणाऱ्या धड्याशी जोडलेला आहे.
