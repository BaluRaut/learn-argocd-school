🤖 ArgoCD शाळेच्या पद्धतीने शिका — GitOps सह & शिवाय

Learn Kubernetes School चा भावंड-कोर्स: तो शिकवतो तुमचे ॲप काय चालवते — हा शिकवतो ते काय deploy करते आणि प्रामाणिक ठेवते. तुम्ही तेच डेमो ॲप तीन प्रकारे deploy करता — हाताने, CI/CD push pipeline ने, आणि ArgoCD ने — आणि प्रत्येक पुढची पायरी का आहे हे नेमके अनुभवता.

🚪 भाग 1 — ArgoCD शिवाय

  • हाताने deploy करा — आणि काय deploy केले ते विसरा
  • configuration drift ला भेटा, मूक मारेकरी
  • push pipeline ने automate करा (कुरिअर रोबोट 📮)
  • …आणि push जे अजूनही दुरुस्त करू शकत नाही ते शोधा

📖 भाग 2 — ArgoCD सह

  • git सत्याचा एकमेव स्रोत बनतो
  • केअरटेकर रोबोट 🤖 cluster च्या आत राहतो
  • drift परत फिरवला जातो; deploy = commits
  • rollback = git revert · audit = git log

🗺️ संपूर्ण चित्र — एक आकृती, दोन्ही जगे

संपूर्ण कोर्स एका कॅनव्हासवर: PUSH जग (लाल, धडे 1–4) त्याच्या चार त्रुटींसह, आणि PULL जग (हिरवे, धडे 5–12) त्याच्या सहा विजयांसह. 4K आवृत्तीसाठी क्लिक करा — wallpaper-आकाराच्या संदर्भासाठी उत्तम.
