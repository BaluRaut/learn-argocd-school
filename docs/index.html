🤖 Learn ArgoCD the school way — with & without GitOps

The sister course to Learn Kubernetes School: that one teaches what runs your app — this one teaches what deploys it and keeps it honest. You deploy the same demo app three ways — by hand, with a CI/CD push pipeline, and with ArgoCD — and feel exactly why each step up exists.

🎒 by hand📮 CI/CD push 📖 GitOps🤖 ArgoCD pull 🪑↩️ self-heal⏪ git-revert rollbacks

🚪 Part 1 — WITHOUT ArgoCD

  • deploy by hand — and forget what you deployed
  • meet configuration drift, the silent killer
  • automate with a push pipeline (courier robot 📮)
  • …and discover what push still can't fix

📖 Part 2 — WITH ArgoCD

  • git becomes the single source of truth
  • the caretaker robot 🤖 lives inside the cluster
  • drift gets reverted; deploys = commits
  • rollback = git revert · audit = git log
